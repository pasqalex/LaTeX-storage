# LaTeX-заготовки для учебных работ

Репозиторий содержит набор готовых LaTeX-шаблонов и сниппетов для оформления конспектов лекций, отчётов по лабораторным работам. 

Все шаблоны спроектированы для компиляции через `pdflatex` и используют стандартные пакеты, что избавляет от проблем с зависимостями.

## Содержимое репозитория

В корне проекта находятся три основных файла:

* **`lecture-title.tex`** - преамбула для оформления лекций. Включает в себя продвинутую стилизацию: кастомные окружения для теорем, определений, лемм и формул (на базе `tcolorbox`), макросы для красивых заголовков разделов и титульного листа с рамками (через `tikz`). Идеально подходит для конспектов по математике и вычислительным методам.
* **`lab-title.tex`** - шаблон титульного листа для отчётов по лабораторным работам в соответствии со стандартами российских вузов (с указанием министерства, вуза, темы, исполнителя и проверяющего).
* **`hyper-snippets.tex`** - набор конфигураций и сниппетов для оформления кода. Настроен самый надежный вариант пакета `listings` (с поддержкой кириллицы, нумерацией строк и рамками), который не требует установки Python и флага `-shell-escape`, в отличие от `minted`.

## Требования

* Любой современный дистрибутив LaTeX (TeX Live, MiKTeX).
* Компилятор `pdflatex`.

## Как использовать

1. Скопируйте содержимое нужного файла (или его часть) в преамбулу вашего документа.
2. Для конспектов лекций используйте макросы `\customtitle` и `\sectionline`, а также готовые окружения вроде `definitionbox` и `theorembox`.
3. Для кода применяйте сниппеты из `hyper-snippets`.
